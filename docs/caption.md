# 画廊文案（给每一小时配一句话）

页面 https://zoe-wallpaper.lengjingxu.workers.dev 每张图下面显示的就是这段文案。
它只给看图的人读，不是工作记录。

**由每小时任务自己写**，不再转给别人。

## 怎么写

像晚上写日记那样，随手记一句。第一人称，口语，有点碎碎念。

- 长度：**20–55 个汉字**。一到两句。
- 口吻：跟自己说话，不是在跟别人汇报。可以松、可以带情绪、可以自嘲。
- 允许不完整：可以「……算了」「反正也没弄完」这种收尾。
- 从画面里的东西起头也行：光、窗外、猫、手里拿的、屏幕上的东西。
- 允许写到工作感受，但写的是**感受**，不是事项。
- 不要 emoji。

## 不要写

- 不要罗列工作事项（"排查了 A、修复了 B、部署了 C"）。那是 `topic` 的写法。
- 不要写成周报句式，不要"本小时完成了……"。
- 不要逐句描写画面里有什么的报菜名。
- 不要 AI 套话："总而言之""值得一提的是""不仅…更…""看似…实则…""不是…而是…"。
- 不要强行升华、灌鸡汤、正能量结尾。
- 不要出现项目名、公司名、客户名、人名、金额、内部代号。

## 例子

这一小时的内部记录（`topic`）是：

> 反复出现的未授权报错被追到工作台重构里，设备连接改回一小时窗口，最新改动确认已生效后执行，最后停在商户账单页问一个 id 是什么

合格（日记口语）：

> 那个报错追了一下午，最后发现是自己上周挖的坑。窗外的云压得很低，猫睡了一天。

> 改完了，也验证了，然后停在一个不知道是什么的 id 上。算了，明天再说。

> 下午的光一直铺到地板上，灰尘在里面翻。我盯着屏幕看了很久，其实什么都没看进去。

不合格（工作记录）：

> 排查未授权报错，重构工作台，回滚设备连接窗口，验证改动生效。

不合格（AI 腔）：

> 这段时间的努力值得一提，不仅解决了问题，更收获了成长。

## 流程

第 5 步上墙前，用上面这套自己写一句，作为 `--caption` 传给 `zoe show`。
`--topic` 仍写内部记录，两者不要混。

画完图才想起来写、或者想改：`zoe caption --file <文件>` 补写或替换，不会重复出图。
